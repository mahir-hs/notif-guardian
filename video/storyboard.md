# Install video storyboard (English captions, ~2 min)

Record in one continuous take per scene. Pause a second on each screen so captions can sit on it.

| # | Scene | What to do on the phone | Caption |
|---|---|---|---|
| 1 | Problem | Show a lock screen with a WhatsApp/Telegram notification arriving late (or just the home screen) | Notifications arrive late on Xiaomi? Here is the fix. |
| 2 | Download | Open the browser, go to the GitHub latest release, tap NotifGuardian-x.y.z.apk | Step 1: Download the APK from the latest release |
| 3 | Install | Tap Install, then Open | Step 2: Install it like any download and open it |
| 4 | Notification access | Tap the row, allow it. If blocked: App info, three dots, Allow restricted settings | Step 3: Allow notification access |
| 5 | Alerts | Allow Guardian's notifications | Allow Guardian's alerts |
| 6 | Battery / Autostart / Frozen | Tap each row, set Battery saver to No restrictions, turn Autostart on | Set Battery saver to No restrictions and turn on Autostart |
| 7 | Add apps | Tap Add apps, pick WhatsApp, Telegram, Gmail | Step 4: Pick the apps you care about |
| 8 | Helper | Keep Google Play services awake, Install, install the helper | Step 5: Install Guardian Helper |
| 9 | Helper rows | Modify system settings on, autostart on, battery No restrictions, Open helper, confirm, Test helper | Turn every row green |
| 10 | Done | Show all green on the home screen | All green: you are done. |

Raw clips land in `video/raw/`, the final video in `video/out/`.
